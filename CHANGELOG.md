# Changelog

## Documentation generator baseline

- Added the initial `docgen` CLI.
- Added repository scanning, Python AST analysis and dependency detection.
- Added Markdown generators for README, architecture, API, diagrams, Q&A, roadmap and summary.
- Integrated `python-rag-framework` for repository indexing and retrieval.
- Integrated `python-agent-runtime` for prompt execution.
- Added deterministic local generation for examples and tests.
- Added optional OpenAI, Anthropic and Gemini provider adapters.
- Added `docgen.toml`, custom exclude patterns, dry-run output preview and example generated docs.
- Added pytest, Ruff, mypy, MkDocs, GitHub Actions CI and GitHub Pages deployment.
